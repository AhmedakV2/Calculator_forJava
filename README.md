## 📖 About The Project
This is a desktop calculator application built using **Java** and the **Swing** library. The project was developed to demonstrate Object-Oriented Programming (OOP) concepts and event handling mechanism in Java. It features a clean, user-friendly interface that performs standard mathematical operations.

## 🚀 Features
* **Standard Operations:** Addition, Subtraction, Multiplication, Division.
* **Clear Function:** Reset the input field with the 'C' button.
* **Error Handling:** Handles exceptions like division by zero.
* **Responsive GUI:** Designed with Java Swing components.

## 🛠️ Built With
* **Java** (JDK 8 or higher)
* **Java Swing** (GUI Toolkit)
* **AWT** (Abstract Window Toolkit)
